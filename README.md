# ng-hpo-uikit

ng-hpo-uikit is an Angular library designed to support Tauri/Angular applications for biocuration with
Human Phenotype Ontology and GA4GH Phenopacket Schema.

## Installation

Add the following to your `package.json` file.

```json
"dependencies": {
  "ng-hpo-uikit": "github:P2GX/ng-hpo-uikit#dist-build"
}
```
